# RevenueForge

Compliance-first, human-in-the-loop AI revenue development system.

## Purpose

RevenueForge helps find, qualify, prepare, approve, track, and convert:

- Freelance/job opportunities
- Sales prospects
- Product leads
- Automation service clients

## Core rules

- No platform bypassing.
- No spam.
- No fake experience.
- No prohibited scraping.
- No mass automation.
- Human approval before restricted actions.

## Current production components

- SQLite CRM database
- Job opportunity intake
- Opportunity scoring
- Scam-risk detection
- Proposal drafting
- Manual approval state
- CLI interface
- Tests
